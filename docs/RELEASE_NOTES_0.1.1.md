# MarkPDF v0.1.1

**[下载 Windows x64 安装包](https://github.com/QianMo0729/MarkPDF/releases/latest)**

下载 `MarkPDF_0.1.1_x64-setup.exe`，双击即可安装，无需准备开发环境。

## 新增与改进

### 录音跟随 PDF

- 每份课件直接管理自己的多段录音，可在 PDF 顶部切换录音、回放或只阅读。
- 新录音保留已有录音；旧录音入口仍会打开对应的 PDF。
- 支持把课件移到另一课程，同时调整其录音归属并保留笔记与转写。

### 更自由的阅读布局

- 标签栏「+」左侧新增分栏图标。一键上下分栏，当前标签保留在上方，上一个标签进入下方；右键可选择左右分栏。
- 每栏保留标签栏与「+」，可以拖动组合内容、调整分栏大小，布局自动保存。
- PDF 内链、目录、搜索与页码跳转增加返回和前进，恢复页内阅读位置。

### 本地翻译与可选 AI

- 默认中英离线互译，使用 Mozilla Bergamot 引擎。首次需下载模型，此后可离线使用。
- AI 设置支持 OpenAI 与 Claude 发送格式，地址、密钥和模型由用户填写；兼容 Chat Completions、Responses 与 Messages。
- 请求不再固定发送温度参数，改善部分模型或兼容服务拒绝请求的问题。
- 转写面板新增独立的实时翻译开关，完整句逐条翻译并保存。

### 转写与上下文纠错

- 未完成的句子也会自动跟随；上滚查看、触摸回看或键盘阅读时暂停，可一键回到最新。
- 新增上下文纠错开关，**默认关闭**。开启后使用已配置的 AI 服务，结合前后句辅助纠正同音词等识别错误。
- 修正句保留原始转写，可展开核对并搜索原文；修正文对应的翻译会更新。
- 翻译与纠错可分别关闭，不影响录音。

### 保存与切换更稳妥

- 切换录音时，过期的加载结果和音频事件不会覆盖当前选择。
- 分栏或切换阅读模式时保留最新笔记草稿，保存失败时保留草稿供重试。
- 快速离开页面时保存最后的分栏布局。
- 打开录音默认显示当前 PDF 笔记，历史笔记仍可手动选择。

## 升级前请先做这几步

1. **结束正在进行的录音**，等待录音结束与笔记保存。
2. 完全退出 MarkPDF。
3. 备份本地数据目录 `%APPDATA%\com.markpdf.app\`，包括其中的数据库、PDF 和录音文件。
4. 运行新安装包。v0.1.1 沿用原有数据目录，升级时请保留该目录；若向导先卸载旧版，请勿勾选删除应用数据。

本次提供 Windows x64 安装包。模型首次下载需要网络；AI 功能需要自行配置可用服务。安装包未签名，Windows 可能显示 SmartScreen 提示，请确认下载来源为本仓库 Releases 页面。
