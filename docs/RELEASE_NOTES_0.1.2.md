# MarkPDF v0.1.2

**[下载 Windows x64 安装包](https://github.com/QianMo0729/MarkPDF/releases/latest)**

下载 `MarkPDF_0.1.2_x64-setup.exe`，双击即可安装，无需准备开发环境。

## 新增与改进

### 录音管理与重新转写

- 选中某段录音后，PDF 顶部的录音栏直接显示「重命名」和「删除」按钮；删除会一并清理该录音的音频文件、转写和总结。录音进行中不可删除。
- 回放时可用本机模型对整段录音重新转写：转写面板头部的刷新按钮、空状态里的「用本机模型转写这段录音」和「更多」菜单都能发起。已有转写时会先确认，确认后替换设备转写及其纠错 / 翻译；失败或取消不影响原有转写。
- 重新转写按当时的翻页事件把每句归到对应页面，转写过程显示进度并可取消。

### 转写模型分档

- 「设置 → 转写模型」按下载大小分为轻量（≤200 MiB）、标准（≤500 MiB）、高精度（≤1000 MiB）、旗舰（≤2000 MiB）四档，每个模型标注发布日期、精度、语言和运行时内存占用（实测或预估）。
- 新增 2025 年发布的中文模型（small-ctc、大模型、XL，含 int8 / fp16），以及英文 LibriSpeech + GigaSpeech 模型。
- 已就绪的模型可分别指定为中文 / English 默认模型；未指定时使用内置默认，缺失时自动回退到该语言其他已就绪模型。

### 用 ChatGPT 账号（Codex）接入 AI

- 「设置 → 翻译与 AI」新增「接入方式」：自定义 API（原有）或 ChatGPT 账号（Codex）。
- 选择 Codex 后，MarkPDF 通过本机 Codex CLI 登录并使用你的 ChatGPT 订阅额度，翻译、解释和上下文纠错都不需要 API Key。登录与令牌由 Codex 自己保存，MarkPDF 不保存凭据。
- 可从账号可用的模型列表中选择模型和推理强度，查看本周额度并测试连接。需要先安装 Codex CLI（`npm install -g @openai/codex`），或在设置里填写 codex.exe 路径。
- 自动检测兼容 npm 将平台二进制装在 Codex 包内部的布局，修复已安装 CLI 却提示“没有找到”的问题；启动或版本检测失败会显示具体错误。

### 编辑与界面修正

- 文本框在触控或触笔下拖动、缩放时不再被浏览器当作页面平移，松手后位置正确保存。
- 实时预览中的公式在光标离开 `$…$` / `$$…$$` 后立即渲染，不再以整行为单位。
- 编辑器与阅读视图中的 KaTeX 公式尺寸和行距统一。
- 设置页「接入方式」的分段按钮不再因说明文字过长而换行、被裁切。

## 升级前请先做这几步

1. **结束正在进行的录音**，等待录音结束与笔记保存。
2. 完全退出 MarkPDF。
3. 备份本地数据目录 `%APPDATA%\com.markpdf.app\`，包括其中的数据库、PDF、录音和模型文件。
4. 运行新安装包。v0.1.2 沿用原有数据目录，升级时请保留该目录；若向导先卸载旧版，请勿勾选删除应用数据。

本次提供 Windows x64 安装包。模型首次下载需要网络；AI 功能需要自行配置服务或登录 ChatGPT 账号。安装包未签名，Windows 可能显示 SmartScreen 提示，请确认下载来源为本仓库 Releases 页面。
