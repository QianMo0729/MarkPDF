# MarkPDF 0.1.4

本次修复适用于 Windows 和 macOS，另包含 macOS 窗口布局修复。

## 修复与改进

- 选择 ChatGPT 账号（Codex）后，翻译与解释面板不再要求填写自定义 AI 服务地址或 API Key。登录失效时显示实际登录错误。
- 已有录音时，橡皮擦右侧仍保留录音按钮，点击可选择“继续录音”或“新建录音”。顶部录音栏也增加“继续录音”。
- 续录追加到所选录音的末尾，保留原音频、开始时间、翻页记录和转写；录音时长及新增记录从原时长继续。
- 续录前校验原音频，并恢复异常退出时未更新的 WAV 文件头；文件缺失或格式不兼容时提示错误，避免覆盖已有内容。
- macOS 阅读页为红绿灯固定预留位置，主界面导航项下移；退出全屏和缩小窗口后不再遮挡按钮及文字。Windows 保持原生标题栏布局。
- 录音栏支持窄窗口换行，长课件标题可收缩。

## 下载与安装

- Windows x64：`MarkPDF_0.1.4_x64-setup.exe`，校验文件 `SHA256SUMS.txt`。安装包未进行 Windows 代码签名。
- macOS Apple 芯片：`MarkPDF_0.1.4_aarch64.dmg`，校验文件 `SHA256SUMS-macos.txt`。应用与 DMG 使用 Developer ID 签名，通过 Apple 公证并附带公证票据。
- 升级前结束录音并退出旧版；保留应用数据目录即可继续使用原课件、笔记、录音及模型。
